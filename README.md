# ZR. Saimun portfolio

# https://zrsaimun.github.io/zr-saimun-portfolio

Vite + Three.js animated personal portfolio.

Install Node.js, then run `npm ci` and `npm run dev`.
Build for hosting with `npm run build`. The output is in `build/`.
Source files and images are in `dist/`.

AI destination images are labelled as illustrations in the galleries.
